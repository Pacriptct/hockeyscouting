Drop CSV files here and they get pulled in on the next run.

Column names just need to be recognizable, for example:

    First Name,Last Name,Team,League,Level,Pos,DOB,GP,G,A,PTS,GAA,SV%,Email,Instagram

`Name` works instead of first/last. `YOB` works instead of `DOB`. `Level` is
optional and should match one of the levels in config.yaml (Tier II,
Tier III Top, Prep, 18U AAA, ...).
